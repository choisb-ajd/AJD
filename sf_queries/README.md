# Snowflake 쿼리 — 재무팀 보고서용

## 파일 목록

| 쿼리 파일 | 대응 엑셀 시트 | 설명 |
|---|---|---|
| `3_계약_내역.sql` | 운영엑셀 > 3_계약 | 전체 계약 내역 (체결 건) |
| `3_계약_취소.sql` | 운영엑셀 > 3_계약-취소 | 취소된 계약 내역 |
| `1_회원_카마스터.sql` | 운영엑셀 > 1_회원_카마스터 | 딜러(회원) 현황 + 실적 |
| `B2G_파트너_광고비_지급.sql` | B2G 광고비 지급 파일 | 딜러별 광고비 + 세금 계산 |

## 사용 방법

1. Snowsight에서 쿼리 실행
2. 결과 우측 상단 **Download** → CSV
3. 엑셀에 붙여넣기

## SF에 없는 데이터 (수동 관리 필요)

- **주민등록번호, 은행명, 계좌번호**: USERS 테이블에 없음
- **광고비요율**: 딜러별 다름 (6%/7%/8% 등), SF에 저장 안 됨
- **프로모션 광고비**: 사전예약/본인혜택/피추천 등 별도 적립 시트에서 관리
- **수기적립 광고비**: 앱 출시 전 적립분, SF 외 관리
